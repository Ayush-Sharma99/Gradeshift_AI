# CLAIMS — GradeShift PrimePath Claim & Evidence Ledger

> **Mandatory Governance Document.**  
> Every technical, operational, and economic statement in the GradeShift PrimePath codebase, UI, documentation, and competition presentation must conform to this ledger.  
> **No synthetic result (`SIMULATED`) or scenario calculation (`ASSUMPTION` / `ILLUSTRATIVE`) may ever be worded as plant validation (`MEASURED` at HMEL).**

---

## 1. Provenance & Evidence Taxonomy

### 1.1 Provenance Labels (`src/gradeshift/provenance.py`)

Every observation, assumption, prediction, and economic output carries one of six explicit provenance tags:

| Provenance Tag | Meaning | Present in Current Repository? |
|---|---|---|
| **`SIMULATED`** | Generated by the seeded synthetic reactor/analyzer/lab simulator (`src/gradeshift/simulate.py`) or derived purely from simulated episodes. | ✅ **Yes** (all process trajectories, lab samples, predictions, intervals, replay metrics) |
| **`ILLUSTRATIVE`** | Controlled fixture or pedagogical walkthrough designed to demonstrate a specific decision branch (`replay.demo_fixture`, Phase 9/10 canonical scenarios, `prob_bad` risk proxy). | ✅ **Yes** (strictly separated from `LOCKED_VALIDATION`) |
| **`ASSUMPTION`** | Explicit policy parameter, residence-time parameter, or economic price/cost/consequence input (`config.ECON_SCENARIOS`, `config.POLICY`, `scale_up_annual`). | ✅ **Yes** (all `₹/tonne` spreads, penalties, sample costs, latency thresholds) |
| **`MEASURED`** | Direct empirical measurement from an actual physical sensor or laboratory instrument in a real plant. | ❌ **No** (enum value exists for future schema compatibility; zero `MEASURED` plant data in repo) |
| **`PUBLICLY_VERIFIED`** | Fact cited from public peer-reviewed literature or published vendor documentation (e.g., commercial APC/analytics landscape). | ⚠️ **Documentation citations only** (`GradeShift_Product_Freeze_Engineering_Handoff.md`) |
| **`INDUSTRY_BENCHMARK`** | Order-of-magnitude petrochemical industry parameter range (e.g., typical fluidized-bed residence time `2–4.5 h`, ASTM D1238 lab turnaround `35–75 min`). | ⚠️ **Problem framing context only** (modeled in code as `ASSUMPTION` / `SIMULATED`) |

### 1.2 Evidence Ladder (`src/gradeshift/validation.py`)

| Evidence Level | Definition | Status in Repository |
|---|---|---|
| **`E0`** | **Assumption** — Explicit parameter or scenario formula input | ✅ Active |
| **`E1`** | **Theory / Formulation** — Mathematical structure, causal firewall, or governance rule | ✅ Active |
| **`E2`** | **Synthetic Simulation** — Evaluated on the frozen 18-event synthetic corpus (`TRAIN` / `CALIBRATION` / `LOCKED_TEST`) | ✅ Active |
| **`E3`** | **Controlled Prototype** — Verified on deterministic software fixtures (fault injection, OOD, VOI, robustness matrix) | ✅ Active (**POC Evidence Ceiling**) |
| **`E4`** | **Historical / Public-Data Validation** — Offline replay on real industrial historian + LIMS logs | ❌ **Not Performed** |
| **`E5`** | **Industrial Validation** — Live shadow-mode or closed-loop trial at an operating plant (e.g., HMEL Bathinda) | ❌ **Not Performed** |

## 3. Reconciliation of Historical / Retired Claims

The initial ideation submission ([`RGIPT_Ayush-Sharma_Idea01.pdf`](../historical/RGIPT_Ayush-Sharma_Idea01.pdf), preserved in [`historical/`](../historical/)) contained controller-first claims that have been **formally retired** under the PrimePath product freeze:

| Retired Historical Claim | Why Retired | Current PrimePath Replacement |
|---|---|---|
| *"Offline CQL Reinforcement Learning controller"* | No RL existed in code; manipulating reactor setpoints requires invasive closed-loop APC/DCS integration. | Read-only commercial-disposition decision engine (`HOLD`, `SAMPLE_NOW`, `PRIME_RELEASE_CANDIDATE`, `ABSTAIN`). |
| *"NMPC + Control Barrier Function (CBF) absolute safety guarantee"* | Static mockup in legacy UI; advisory software cannot certify reactor process safety. | 13 hard policy gates + sensor health + OOD refusal (`ABSTAIN / FOLLOW SOP`) + mandatory human QC authorization. |
| *"Method-of-Moments + LSTM + Adaptive EKF soft sensor with $R^2 > 0.95$"* | Legacy UI mocked predictions with `true_mfi * np.random.normal(1.0, 0.02)`. | Causal 37-feature `GBMQualityEstimator` + `SplitConformalCalibrator` evaluated on whole-event chronological splits (`MAE = 0.272 g/10min` on locked synthetic set). |
| *"44% faster transition, 55% less off-spec, ₹60–102 Cr/yr (or ₹81 Cr/yr) savings"* | Derived from uncalibrated legacy polynomial simulator (defect D1) and unverified top-down arithmetic. | Bottom-up episode mass/value ledger (`LOW`/`BASE`/`HIGH` scenarios) + locked counterfactual replay (`0 t` false-prime mass) + explicit scenario scale-up function labeled `SIMULATED` / `ASSUMPTION`. |
