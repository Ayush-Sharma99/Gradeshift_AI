## 1. Data & Validation Limitations

1. **100% Synthetic Corpus (`E2` / `E3` Ceiling):**
   - All process trajectories (`H2_ratio`, `bed_temp`, `MFI_online`), residence-time washout curves, analyzer lags, and laboratory sample schedules in this repository are generated by the seeded synthetic simulator (`src/gradeshift/simulate.py`).
   - Zero HMEL Bathinda historian tags, LIMS records, or commercial financial ledgers were used (`E4 = 0`, `E5 = 0`).
2. **Small Independent Calibration Event Count (`3` Events):**
   - Split-conformal calibration (`src/gradeshift/calibrator.py`) uses `141` labeled rows drawn from only `3` independent calibration episodes (`EP-BC-00`, `EP-CA-01`, `EP-CA-02`).
   - Because rows within a transition episode are temporally correlated and transition directions shift across chronological partitions, empirical locked coverage is `0.6596` (`235` rows across `5` events) compared to the `0.90` nominal target (`0.9078` on calibration).
   - Subgroup-conditioned conformal calibration is explicitly gated off (`conditioning_gated = true`) because `3 < 5` (`MIN_EVENTS_FOR_CONDITIONING`).
3. **Zero Natural Prime Candidates on `LOCKED_TEST` (`100%` Abstention):**
   - Whole-event chronological splitting assigns `EP-BC-01`, `EP-BC-02`, `EP-CB-00`, `EP-CB-01`, and `EP-CB-02` (`B->C` and `C->B`) to `LOCKED_TEST`, while `TRAIN` contains only `A->B`, `A->C`, `B->A`, and `C->A`.
   - Because `ApplicabilityDetector` is fitted strictly on `TRAIN`, it flags `B->C` and `C->B` as `UNSUPPORTED` (`ABSTAIN_APPLICABILITY`), causing PrimePath to abstain on all `235` locked decisions.
   - Consequently, active `PRIME_RELEASE_CANDIDATE` and `SAMPLE_NOW` behavior is demonstrated via the separate, explicitly labeled `ILLUSTRATIVE_DEMO` fixture (`replay.demo_fixture`), never by weakening the locked validation gates.

## 2. Modeling & Physical Scope Limitations

4. **Single-Property Modeling (`MFI` Only):**
   - The POC models Melt Flow Index (`MFI`, g/10min) as the single dynamic analyte of record. Polymer density (`g/cm³`) is carried in `GradeSpec` as static context only and is not dynamically estimated.
5. **Simplified Residence-Time & Mixing Model:**
   - Downstream material identity (`src/gradeshift/material_identity.py`) uses an idealized CSTR / Erlang residence-time distribution ($\tau = 150\text{ min}$, transport delay $25\text{ min}$) with explicit uncertainty bands, not a plant-calibrated CFD or multi-vessel extruder/conveying model.
6. **Provisional Risk Proxy (`prob_bad`):**
   - Prime candidacy is gated by the two-sided calibrated conformal interval (`[lower_mfi, upper_mfi] <= [mfi_low, mfi_high]`). The scalar `prob_bad` used inside expected-loss tables is explicitly labeled a provisional/illustrative proxy, not a calibrated tail probability.
7. **Diagnostic-Only Oracle:**
   - The `ORACLE_DIAGNOSTIC_ONLY` policy in counterfactual replay accesses post-decision laboratory truth solely to establish a theoretical lower bound on avoidable loss and is never achievable in live operations.
